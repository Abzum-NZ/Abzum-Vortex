# Historical Module V1 definition baseline

This directory preserves the complete Definition source and resolution inputs that
were current immediately before the editable CRM and Service Desk Modules moved to
Module source contract `2.0.0`. Historical V1 compilation, publication, consumer,
restore, and draft-conversion tests read these files directly.

These files are immutable test evidence. They are not the current application
fixture gate and must not be regenerated by reverse-converting newer definitions.
Their parsed JSON values preserve the original source and resolution evidence;
filesystem end-of-file newline formatting is not published release evidence.
