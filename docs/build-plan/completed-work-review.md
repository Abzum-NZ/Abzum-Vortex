## Confirmed literal-reference defect

[#258](https://github.com/Abzum-NZ/Abzum-Vortex/issues/258) has the source links and required regressions. The reproduction extracted the exact `requireResolvedRecordTypeReferences` helper from the reviewed commit and removed only TypeScript annotations for an isolated JavaScript run. Passing `{settings:{payload:{kind:"literal",value:{state:"unresolved",qualifiedKey:"sample:item"}}}}` produced a refusal at `settings.payload.value`. It never touched the workspace source or a database. The surrounding schema explicitly permits literal JSON. Full compiler/persistence regressions must be added when implementing the correction.

The correction is typed traversal, not reserving business-data property names, silently deleting data, or weakening actual reference validation.

## Simplicity and hardcoding review

- Keep service ownership, exact published dependencies, immutable history and transactional concurrency checks. They protect specific invariants.
- Remove the lifetime publication cap via [#257](https://github.com/Abzum-NZ/Abzum-Vortex/issues/257); bound per-request work instead.
- Do not copy Fluid's filesystem persistence, fallback seeds, example data, unscoped storage or guess-by-shape slot traversal. Adapt its editor interactions behind the [Vortex page contracts](../specification/appendices/page-builder-contracts.md).
- Keep the HR example entirely in Vortex definitions. Manager selection, HR fallback, pending-without-approver and no self-approval are ordinary workflow/condition/action configuration, not custom code.
- The large compiler/validator/comparator have repeated traversal concerns. Address the affected paths with focused shared typed traversal while implementing [#258](https://github.com/Abzum-NZ/Abzum-Vortex/issues/258)/[#249](https://github.com/Abzum-NZ/Abzum-Vortex/issues/249), not a parallel compiler, new expression language or wholesale rewrite.
- A task is not implemented because its contracts or fixture exist. Page runtime, workflows, file sharing and MCP parity still require their owning tasks and integration evidence.
