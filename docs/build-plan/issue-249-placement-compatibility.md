# #249 — Unify application definitions and remove obsolete formats

Applications use one complete definition for pages, layouts, settings and appearance. Changing an application no longer requires maintaining an unused older format.

The current bounded scope, specification references, subtasks, dependencies, model assignments and estimates are maintained in [#249](https://github.com/Abzum-NZ/Abzum-Vortex/issues/249). Follow that issue body and the [development roadmap](README.md).

This pointer replaces the earlier implementation packet. Its former compatibility, proof, database, hosted and test instructions are no longer development requirements.
