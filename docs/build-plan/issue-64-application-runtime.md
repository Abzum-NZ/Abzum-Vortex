# #64 — Install and open definition-led applications

An authorised person can install an application, open its pages and deliberately adopt a newer release. Each organisation has its own available applications and starting page.

The current bounded scope, specification references, subtasks, dependencies, model assignments and estimates are maintained in [#64](https://github.com/Abzum-NZ/Abzum-Vortex/issues/64). Follow that issue body and the [development roadmap](README.md).

This pointer replaces the earlier implementation packet. Its former compatibility, proof, database, hosted and test instructions are no longer development requirements.
